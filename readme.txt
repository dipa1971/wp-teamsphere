Manage employee profiles, departments and teams, and publish a team directory.

== Description ==

WP TeamSphere combines employee profile management, team organization and a public team directory in one standalone plugin.

This is a development build covering Milestone 1 (core foundation): employee profiles, departments, teams, skills, permissions and privacy foundations.

== Installation ==

1. Upload the `wp-teamsphere` folder to `/wp-content/plugins/`.
2. Activate the plugin through the Plugins screen.
3. Open WP TeamSphere in the admin menu.
